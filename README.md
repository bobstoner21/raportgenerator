# LSPD / LSSD Report Generator (static, GitHub Pages)

Статический генератор репортов для форума на XenForo. Полностью работает
в браузере, без сервера и без PHP/phpBB — просто HTML + CSS + JS в одном
файле `index.html`.

Пользователь заполняет форму (вкладки Incident / Arrest / Traffic /
Use of Force / Complaint / Property / CCW Notice / Internal), жмёт
**«Сгенерировать BBCode»**, и получает:

- готовый **заголовок темы**;
- готовый **текст сообщения в BBCode**, точно в том же формате
  (`[coll]`, `[a=]`, `[doc_b=]`, `[textarea]`, `[cb]`/`[cbf]` и т.д.),
  что использовался в исходном phpBB-генераторе.

Дальше это просто копируется кнопкой «Копировать» и вставляется в
создание новой темы на форуме.

## Как захостить на GitHub Pages

1. Создайте новый репозиторий на GitHub (публичный или приватный —
   Pages работает и с приватными, если есть GitHub Pro/Team/Enterprise;
   для публичных репозиториев работает бесплатно).
2. Загрузите в него файл `index.html` из этого архива (в корень репозитория).
3. Зайдите в **Settings → Pages**.
4. В разделе **Build and deployment → Source** выберите **Deploy from a branch**.
5. Branch: `main` (или та ветка, куда загрузили файл), папка — `/ (root)`.
6. Сохраните — через 1–2 минуты сайт появится по адресу вида
   `https://<ваш-логин>.github.io/<название-репозитория>/`.

Больше ничего настраивать не нужно — файл самодостаточный.

## Важно про кастомные BBCode-теги

Теги вроде `[coll]`, `[coll3]`, `[coll4]`, `[coll6]`, `[a=]`, `[doc_b=]`,
`[textarea]`, `[cb]`, `[cbf]` — это **не стандартные** BBCode-теги. На
исходном phpBB-форуме они были заведены как кастомные BBCode-стили
(отвечали за таблицы/колонки/оформление). Чтобы сгенерированный код
красиво отображался на XenForo, эти же теги нужно **завести там же**
через **ACP → BB Codes → добавить новый BB Code**, прописав для каждого
свой HTML/CSS-шаблон замены. Сам генератор их не создаёт — он только
собирает текст в этом формате, один в один как раньше.

Если хотите, чтобы теги назывались иначе (например, под уже готовый
набор BBCode на вашем XenForo) — нужно просто переименовать теги внутри
`index.html` в блоке `<script>` (функция генерации в самом низу файла).

## Что изменилось по сравнению с исходной phpBB-версией

- Убрана вся серверная логика (PHP, submit_post, авторизация, редиректы
  на форум) — теперь это просто статическая страница.
- Вместо автоматической публикации темы форма показывает готовый текст
  с кнопками «Копировать» — вставляете вручную при создании темы.
- Имя офицера и серийный номер задаются один раз вверху страницы и
  сохраняются в браузере (localStorage), автоматически подставляясь во
  все вкладки, где раньше стояло значение из аккаунта форума.
- Логика сборки BBCode для каждого типа отчёта (Incident, Arrest,
  Traffic, UOF, Complaint, Property, CCW, Internal) перенесена без
  изменений — набор полей и итоговый формат кода идентичны исходнику.

## Локальный запуск / тест

Файл можно просто открыть в браузере (`index.html` двойным кликом) —
никакого сервера для этого не нужно.
